# Harmony — музыкальный клиент (PySide6 + QML, Material 3 стиль)

## Возможности
- **Мобильная версия (Android)**: тот же код, мобильная раскладка включается автоматически; сборка APK через `android/build_apk.sh`, подробности в `android/README_ANDROID.md`. Посмотреть мобильный интерфейс на ПК: `HARMONY_MOBILE=1 python main.py`
- Десктопный интерфейс: боковая панель, широкая сетка, нижняя панель плеера с громкостью; в узком окне (<820 px) автоматически переключается на мобильную раскладку с нижней навигацией
- Векторные иконки (SVG-пути, без эмодзи), анимации: каскадное появление карточек, наведение, волна на кнопках, эквалайзер у играющего трека, плавная смена цвета темы
- Кнопка play/pause в стиле YouTube: треугольник плавно перетекает в паузу, круг становится скруглённым квадратом
- Полноэкранный плеер выезжает снизу, фон — размытая обложка
- Синхронизированный текст песни: панель рядом с обложкой и полноэкранный режим с плеером внизу. Строки подсвечиваются по мере воспроизведения, по клику можно перейти к нужному моменту. Текст берётся из локального `.lrc`/`.txt` рядом с аудиофайлом или из LRCLIB, результаты кэшируются
- Настройки текста песен: цвет строк, активной строки и фона, размер шрифта, выравнивание, автопрокрутка и запуск сразу в полноэкранном режиме
- Библиотека с обложками (встроенные в файлы ID3 / MP4 / FLAC), жанрами и поиском
- Плейлисты и подборки по жанрам, лайки
- Удаление треков из библиотеки (по желанию — вместе с файлом на диске)
- Цвет интерфейса меняется по обложке текущего трека (динамическая тема)
- Импорт:
  - **Telegram** — экспорт чата в Telegram Desktop (папка с `result.json` и аудио)
  - **Плейлист из CSV/TXT** — Spotify через Exportify (CSV), Apple Music / Яндекс Музыка / любой список в виде `Исполнитель - Название`. Обложки из CSV или превью найденных видео скачиваются автоматически
  - **Ссылки** — YouTube, SoundCloud и всё, что поддерживает yt-dlp (треки, альбомы, плейлисты)
  - **Локальные файлы**
- Встроенные **Загрузки**: поиск песни по названию с результатами и превью, скачивание выбранного трека или прямой ссылки
- **Настройки**: динамическая тема, оформление текста песен, удаление файлов, папка и формат загрузок, скачивание обложек, статистика библиотеки и выбор языка интерфейса
- Язык интерфейса: Українська, Русский, English
- Все файлы сохраняются в `data/` и доступны офлайн

## Установка и запуск

```bash
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Для загрузки с YouTube и других сайтов может понадобиться установленный **ffmpeg**
(нужен yt-dlp для части форматов).

## Структура
```
main.py            точка входа, регистрирует backend в QML
core/backend.py    мост Python <-> QML (слоты, свойства, фоновые задачи)
core/library.py    библиотека: треки, обложки (mutagen), плейлисты, JSON-хранилище
core/downloader.py поиск и загрузка через yt-dlp (включая обложки-превью)
core/importers.py  Telegram / CSV / TXT / ссылки
core/platform_info.py  определение мобильной платформы и отступов экрана
core/settings.py   настройки приложения (data/settings.json)
core/lyrics.py     локальные тексты, LRCLIB, разбор LRC и кэш
core/i18n.py       словари локализации интерфейса и статусных сообщений
qml/               интерфейс: Main, Sidebar, HomePage, LibraryPage, DownloadPage, PlaylistPage, ImportPage, SettingsPage, ...
android/            скрипт сборки APK, иконка и документация
qml/LyricsView.qml панель и строки синхронизированного текста
qml/LyricsPage.qml полноэкранный текст с плеером внизу
qml/Icons.qml      набор SVG-иконок; Icon.qml рисует их через QtQuick.Shapes
qml/PlayPauseButton.qml  морфинг play <-> pause
qml/Theme.qml      цвета (акцент меняется по обложке)
qml/Player.qml     общее состояние плеера (singleton)
data/              библиотека, обложки, настройки, кэш текстов и загруженные файлы
```

## Ограничения
- Прямой вход в аккаунты Spotify, Apple Music, Яндекс Музыка, VK не реализован (нужны их API и ключи).
  Вместо этого используйте экспорт плейлиста (CSV/TXT) или ссылку.
- Скачивайте только ту музыку, на которую у вас есть права.
- Для формата MP3 при скачивании нужен ffmpeg; M4A скачивается без конвертации.
- При включённой настройке «Удалять файлы с диска» удаление трека стирает и сам аудиофайл — используйте осторожно.
- Для поиска текстов нужен доступ к `lrclib.net`. Без интернета можно положить `.lrc` (с таймкодами) или `.txt` рядом с аудиофайлом — он будет использован первым.
- Нужен PySide6 6.7 или новее (QtQuick.Effects, CurveRenderer).
