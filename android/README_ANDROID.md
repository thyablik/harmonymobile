# Harmony для Android

Это тот же PySide6 + QML код, что и на ПК. На телефоне интерфейс включает мобильную раскладку
(нижняя навигация, мини-плеер, отступы под статус-бар и жестовую панель, кнопка «Назад»).

## Посмотреть мобильный интерфейс на ПК

```bash
# Linux / macOS
HARMONY_MOBILE=1 python main.py
# Windows (cmd)
set HARMONY_MOBILE=1 && python main.py
```
Можно сузить окно мышью. Для проверки отступов: `HARMONY_INSET_TOP=48 HARMONY_INSET_BOTTOM=32`.
Данные в этом режиме лежат в `data/`, как обычно.

## Сборка APK

Нужно: Linux, macOS или Windows через **WSL2**, Python 3.10+, **JDK 17**, ~10 ГБ места и интернет
(при первой сборке скачиваются Android SDK, NDK r28c и Android-колёса PySide6 от Qt).

```bash
./android/build_apk.sh               # debug APK для телефонов (arm64)
ARCH=x86_64 ./android/build_apk.sh   # для эмулятора
```

Готовый `.apk` появится в `build/out/`. Установка: `adb install -r build/out/*.apk`
или скопировать файл на телефон и открыть (разрешить установку из неизвестных источников).

Свои SDK/NDK можно указать так: `ANDROID_SDK_ROOT=... ANDROID_NDK_ROOT=... ./android/build_apk.sh`.

### Что делает скрипт
1. Ставит в `build/venv` ту же версию PySide6, что и в Android-колёсах (по умолчанию 6.12.0, меняется через `QT_VER`).
2. Копирует проект в `build/app` без `data/`, `android/` и десктопных файлов.
3. Кладёт чисто питоновские пакеты **mutagen** и **yt-dlp** в `vendor/`: `pyside6-android-deploy`
   сам ставит в APK только Python, Shiboken и PySide6. `main.py` подключает `vendor/` автоматически.
4. Запускает `pyside6-android-deploy` с модулями Qt Network и Multimedia.

### Релизная сборка (для Google Play)
В `build/app/pysidedeploy.spec` измените `mode = debug` на `mode = release` и подпишите APK/AAB
своим ключом (keystore) по документации buildozer. Идентификатор пакета по умолчанию `org.Harmony.Harmony`.

## Что на телефоне работает иначе
| Функция | На Android |
|---|---|
| Данные (библиотека, обложки, загрузки) | Во внутреннем хранилище приложения, удаляются вместе с приложением |
| Локальные файлы / CSV / TXT | Выбираются системным диалогом и **копируются** в хранилище приложения |
| Импорт Telegram | Папку выбрать нельзя: заархивируйте папку экспорта в **ZIP** и выберите архив |
| Формат загрузок | Только M4A / «Лучший» (нет ffmpeg для конвертации в MP3) |
| Папка загрузок, «Открыть папку» | Скрыты |
| Удаление трека | Долгое нажатие на строку трека (на ПК есть кнопка-корзина) |
| Громкость | Скрыта, используются кнопки телефона |
| Кнопка «Назад» | Закрывает текст песни / плеер / возвращает на главную |

## Известные ограничения и что не проверено
- **APK я не собирал и не запускал на устройстве**: в моём окружении нет доступа к Android SDK/NDK.
  Проверены мобильный интерфейс на ПК (экраны размером с телефон с отступами) и Python-логика
  (импорт из ZIP, копирование из `content://`, подмена формата).
  Первая сборка может потребовать правок, пришлите лог ошибки.
- Фоновое воспроизведение с уведомлением и кнопками на экране блокировки не реализовано:
  для этого нужен Android foreground service, который PySide6 из коробки не даёт.
- Работа yt-dlp на Android зависит от сайта и версии; для YouTube часто нужны свежие обновления
  (пересоберите APK с новой версией `yt-dlp`).
- Нужен PySide6 6.8+ (под Android-колёса 6.12.0); с Qt 6.8+ окно рисуется под системными панелями,
  отступы вычисляются из размера экрана.
- Скачивайте только ту музыку, на которую у вас есть права.
